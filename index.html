AgendEasy

Agendamentos online para barbeiros e designers de sobrancelhas.

O profissional compartilha um link próprio e o cliente agenda sozinho, em três etapas, vendo só os horários livres. No painel ficam a agenda, os clientes, os serviços e o resumo do mês.

Principais funções

  • Agenda diária e semanal: confirmar, concluir, cancelar e reativar
  • Histórico de cada cliente e avaliações no painel
  • Serviços com preço, duração e horário de atendimento
  • Login com Google e painel que vira ícone no celular (PWA)

Tecnologias

  • Python
  • FastAPI
  • SQLAlchemy
  • SQL Server
  • HTML · CSS · JS
  • pytest

SmartEasy

Gestão inteligente para assistência técnica de celulares e tablets.

Um sistema interno para a equipe da loja: a ordem de serviço acompanha o aparelho desde o balcão ou o WhatsApp até a entrega, passando por diagnóstico, orçamento, reparo e testes.

Principais funções

  • Perfis de administrador, atendente e técnico, cada um com sua tela
  • Orçamento, tabela de preços com margem e financeiro
  • Comprovante de entrega e garantia
  • Várias lojas no mesmo sistema, cada uma com seu endereço

Tecnologias

  • HTML · CSS · JS
  • Multiempresa
  • SaaS por assinatura
